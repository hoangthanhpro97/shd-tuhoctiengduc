# Content: Exam Repository

Thư mục lưu trữ nội dung đề thi mẫu và tài nguyên âm thanh (audio stimuli).
Đề thi mẫu được lưu dưới dạng file JSON mô phỏng (ví dụ: `content/exams/demo-b1-mock-02.json`) tuân thủ `docs/ux/08-sample-exam-spec.md`.
Tuyệt đối không lưu đáp án gốc có bản quyền tại đây; mọi nội dung đều là chữ giả minh họa kỹ thuật.
