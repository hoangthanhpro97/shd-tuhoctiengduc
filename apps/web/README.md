# Apps: Web Client & API Gateway

Thư mục giữ chỗ cho ứng dụng web (Next.js / Fastify / Express).
Theo kế hoạch kiến trúc Bước 2, **chưa viết mã nguồn nghiệp vụ** tại thư mục này ở Lệnh 2.1.
Ứng dụng web sẽ là nơi duy nhất lắp ghép các packages: `@shd/contracts`, `@shd/core`, `@shd/db`, `@shd/adapters`.
